# ✨ FutureFirst

**Volunteer Today. Change Future.**

FutureFirst is a volunteer engagement platform designed to turn one-time volunteering into continuous impact.

Built for **Hack for Humanity 2026**, FutureFirst addresses a key challenge identified with Save the Children Action group UNSW- a Non-Profit Organization: **volunteer retention**.

## The Problem

Young people want to make a difference, but they often struggle to stay engaged after their first volunteering experience, access humanitarian and child-rights knowledge in an actionable way, and navigate safe, inclusive opportunities through fragmented digital channels.

The event ends — and often, so does the volunteer journey.

## Our Solution

FutureFirst creates a continuous journey:

**Discover → Learn → Volunteer → Verify → Grow → Next Action → Return**

### Key Features

- Personalised volunteer opportunity matching
- Safe & verified volunteering information
- Humanitarian and child-rights micro-learning
- Verified volunteer hours and participation
- Transferable Skill Passport
- Certificates and personal skill progression
- Smart next-opportunity recommendations
- Organisation dashboard for volunteer retention and event management

## Our Goal

We don't measure success only by registrations.

**We measure whether a first-time volunteer comes back.**

> The event ends. But the volunteer journey shouldn't.
